## 打印参数建议

| 参数 | 值 |
|---|---|
| 材料 | PLA(或 PETG 更耐温) |
| 层高 | 0.2mm |
| 壁厚 | ≥3 层(≥0.6mm) |
| 填充 | 30%(盖子) / 50%(重心摆、连杆) |
| 支撑 | 重心摆球头朝下打印需支撑；其余零件可免支撑 |
| 回缩 | 启用(球窝是悬垂面) |

## 装配步骤

### 准备
1. 打印全部零件，清除支撑
2. 攻丝：钢球 M3 螺纹孔、盖子中心 M16 螺纹（如果打印螺纹不够精确，用丝锥过一遍）

### 装配
1. **底部配重**：钢丸/铅粒 + 环氧胶填入壳体底部(约40g)，固化后打磨平整
2. **盖子**：安装到壳体上（用 6×M3 螺栓+螺母固定到壳体翻边）
3. **舵机**：用 4×M2 自攻螺钉将左舵机固定到盖子上方左侧位置
4. **右舵机**：**先旋转 180°**（安装孔互换），再用 4×M2 自攻螺钉固定到右侧位置
5. **舵机臂**：装入舵机输出轴（检查相位：左 15°、右 150°），用舵机自带螺钉紧固
6. **重心摆球头**：旋下球铰盖，将重心摆的球头（Ø8mm）压入盖子中心的球窝
7. **球铰盖**：旋上球铰盖，调整预紧（能自由摆动但不旷量），可用螺纹胶固定位置
8. **钢球**：在重心摆底部 M3 螺纹上涂螺纹胶，拧入钢球（M3 贯通孔），两端加 M3 螺母防松
9. **连杆**：将连杆一端球头（Ø6mm）扣入舵机臂末端球窝，另一端扣入重心摆连接座上的锚点球窝
10. **导向环**：用 4×M2 自攻螺钉固定到盖子下方，导向销插入滑槽
11. **装入壳体**：整体重心摆+连杆系统装入壳体内部，确认运动无干涉
12. **电子件**：ESP32 + IMU 安装到壳体内部空位，接线见 esp32/README.md

### 调试
1. 上电，舵机回中性位（`cal` 命令）
2. 手动拨动重心摆，确认球铰灵活、连杆无卡滞
3. `sway` 命令验证全方向运动
4. `balance` 命令进入闭环模式
